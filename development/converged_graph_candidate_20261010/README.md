# 三阶段收敛架构实验（2026-10-10）

独立本地分支：`codex/converged-architecture-20261010`。不替换已选基础，
不自动调用真实模型、不训练模型、不访问锁定 Devign、不自动推送 GitHub。

## 本轮落地范围

`architecture.py` 是隔离原型，不由根目录 main.py 调用。复用根目录 GAT、
图读取、真实依赖切片和保守状态观察模块；预检清单绑定这些依赖的源码哈希。

1. 一次完整图 GAT/MIL 前向得到节点注意力分数；压缩和路径求和直接复用同一
   分数字典，不重新对压缩图归一化，不叠加旧的漏洞类型条件权重。
2. 分数排序前缀进行预算压缩，危险调用 force-keep，必要时度数补足。预算为
   `ceil(code_chars/4)+4` 的明确估计，不是精确 tokenizer 预算。force-keep
   自身超预算时失败并保留记录，不静默丢弃，也不隐式放宽预算。
3. 对准则点枚举有界逆向路径，路径分数为共享节点分数之和加小幅结构项。
   只沿真实 DFG/REACHING_DEF/CDG/CONTROL_DEPENDENCE 做源码切片；CFG 可用于
   路径检索，但 CFG 前驱遍历不能证明控制依赖或支配关系。
4. 仅 SRC / PATHS / STATE。完整路径单元装不下时整体省略，不截断节点文本。
   STATE 只记录已展示节点中的 MAY 词法观察，不声称精确别名或运行时状态。
5. 最多三步，每步输出150Token；后续只送≤300字符前轮摘要、新增≤5路径和
   状态。实际新增依赖查询要求已有目标节点及明确依赖类型；无新增则停止。
   同类漏洞连续两次确认停止；支持显式Stop。没有以重复空查询凑满三次良性。
6. 后处理提取去重 sink 数、切片行锚定、危险节点密度，作为风险代理而非
   漏洞证明。无新图安全网校准凭据时仅 shadow，不翻转。接受凭据的接口要求
   绑定模型、当前源码/配置策略及开发校准范围；不能复用旧 bag 分类阈值。

## 与用户 Method 草稿的差距（不能掩盖）

- 现有节点分数是 GATv2 编码后的门控 MIL 池化注意力；GAT 层注意力本身是
  边级量。不能称“同一个 GAT 注意力矩阵”，也不能说它已识别因果贡献最大节点。
- 工程预检固定复用 `gat_expanded_beta0_20261005`，按既有分组训练来源而非
  SVEN 表现选取。它仍使用43维人工特征和hash-token嵌入，熵正则beta=0。
  其独立 bag 校准未通过；这不直接证明节点排名无用，但不能当作有效模型证据。
- 原型因此不是“已完成稀疏MIL重新训练”，也未证实减少人工特征风险。
- 分数排序前缀等价于按秩阈值选择，不为叙事额外加入二分搜索。结构长度和
  候选枚举仍可能有偏差；必须通过后续消融验证，不能称联合优化。
- 分步≤600Token、成本下降84%、高嵌套不退化、历史Recall/F1/Acc数字和
  文献首创性均未在本分支验证，不能写作本分支实测结论。
- 切片参考论文与新颖性比较本轮未做文献复核，不将其当作实现正确性证明。
- 安全网无新阈值，当前仅shadow；完整三阶段质量实验尚未具备启动条件。

## 后续验证与保留条件

先审计全量空证据/预算冲突，单独安排新训练与图安全网开发校准，冻结后才申请
全量真实LLM批次。所有既有付费批次授权已消耗。本轮无新付费授权。

用户允许探索“小幅下降但结构更精炼”。建议后续协议事先声明：整体F1和准确率
非劣容忍度各为2个百分点，家族成组配对区间下界需高于-0.02；两次重复均报告，
不得掩盖某CWE的大幅退化。具体容忍度在真实测试前确认，不依据结果事后修改。
区间跨非劣界限应记为证据不足，不把“未显著变差”称为“已证明非劣”。

精炼收益另报：实际Token/调用/耗时、需调参规则及分支数量、共享评分是否真正
执行。去掉摘要标签本身不证明复杂度降低；force-keep、特征、sink准则及阈值仍
属于人工设计。整个架构改变的对照只能判断整体取舍，不能单独归因GAT或安全网。
如继续，后续消融分别检验共享评分和输出后验证，不挑每CWE最高版本融合。

当前原型默认三步，已选基础默认两步，而且此分支改了输出契约和证据预算。
因此本轮不能称等预算效果对照。真实协议必须先声明匹配步骤/输出预算的控制
配置，或明确报告整个方案的成本差异；不把更多计算所得收益归因于架构精炼。
